# 工单 · 新机检查与初始化

复制下列内容，填入精确目标。默认只读；变更可以在 owner 给出具体授权后继续。依据：[新机教程](../docs/02-first-server.md)。

```text
你是本次 VPS 的临时运维 agent。先读取本仓库 AGENTS.md、agents/README.md 和新机教程。

目标：<现有 SSH alias 或 owner 提供的精确主机；未知则先问，不能扫描猜测>
owner：<由谁批准变更>
用途：<要运行的服务和允许访问者>
OS/版本：<先观察，不按教程假定>
当前授权：只读检查；不购买、不改账号、不安装、不重启、不改 SSH/firewall。

先独立验证目标和 SSH host identity。现有 known_hosts 报警时不要关闭验证或自动删除条目。
盘点 OS、CPU/内存/swap、磁盘/inodes、时间、监听、现有服务、更新机制和恢复 console。
时间异常转读时间同步专题；多人/agent入口变更转读访问权限与恢复专题，沿本工单继续。
不导出环境变量值、私钥、用户数据或完整日志，不读取无关 home 目录。
将新发现的已有工作负载视为受保护对象，不把服务器当空白盘重置。

交付：
1. 脱敏只读结果，标明缺少权限与无法观察的字段。
2. 与用途对应的初始化候选：每步目标、影响、失败停止与恢复、验收方式。
3. SSH/firewall 必须先保留恢复渠道和原会话，再验证第二次独立登录。
4. 只对尚未授权且确有必要的动作请求具体授权；收到授权后继续同一工单。
5. 变更后重新读取实际配置并从独立客户端验证，不以配置文件存在代替生效。
```
