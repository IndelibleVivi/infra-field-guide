编辑文字或布局可直接修改 SVG；更换小鹿时同时更新原图及 SVG 内嵌数据，再查看实际渲染。显示目标为 900px 宽；正文与落款保留足够对比度。图像和排版按 [LICENSING.md](../../LICENSING.md) 中的原创视觉材料范围授权。
